# Drag-and-Drop

WinMux Desktop підтримує перетягування — як у веб-версії Claude.

## Що можна перетягнути

| З чого | Що відбудеться |
|--------|----------------|
| Файл з Windows Explorer | Шлях (з `\` → `/`) вставляється в термінал |
| Кілька файлів | Список шляхів через пробіл, зі лапками для шляхів з пробілами |
| Папка | Вставляється шлях до неї |
| URL з браузера | Вставляється текстом |
| Зображення з браузера | Зберігається в `drops/`, шлях вставляється |
| Зображення з буфера обміну (Ctrl+V) | Те саме — зберігається в `drops/`, вставляється шлях |
| Текст з будь-якого додатку | Просто вставка |

## Папка для дропнутих файлів

`%LOCALAPPDATA%\WinMux\drops\drop-<timestamp>.<ext>`

Файли там залишаються — періодично можна вичищати. У майбутньому додамо опцію auto-cleanup після N днів.

## Інтеграція з claude

Якщо в командному рядку зараз `claude`, після drag можна одразу запустити:

```bash
claude --image C:/Users/me/AppData/Local/WinMux/drops/drop-1234567.png "опиши що тут"
```

(Майбутні версії будуть додавати `--image` автоматично, зараз треба руками — але шлях уже там)

## Технічні деталі

- Native file drop через Tauri events — працює для Explorer
- HTML5 DnD для URL/тексту/HTML images
- Clipboard API для Ctrl+V image paste
- Файли зберігаються байт-в-байт (без перекодування)
